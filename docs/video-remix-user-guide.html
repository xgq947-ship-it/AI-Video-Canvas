开始前准备

准备项目和参考视频

首次使用先检查四项。Chrome 是 AI 平台登录入口；Evan 不会读取你的日常 Chrome 用户资料。

步骤 01

导入并分析

简单模式会把导入、自动拆镜和结构化分析连在一起。通常只需选择一次视频。

01

选择参考视频

本地文件、分享链接或画布视频三选一

  1. 在画布右键打开“单独添加节点”，选择 短视频复刻模板；也可以对已有视频右键选择 创建视频分析工作流。
  2. 连接已有视频结果作为参考视频，再按需连接产品、人物和场景参考图；四类输入分别落到固定端口。
  3. Evan 自动复制素材、生成分析代理、拆分镜头并开始理解人物、场景、道具、动作与运镜。
  4. 如果出现“Gemini 尚未登录”，点击 打开 Gemini 登录，在弹出的正式版 Chrome 中完成登录，然后返回重试。
导入素材→本地自动拆镜→Gemini 全片分析→进入资产步骤
!
没有登录不会卡住本地功能

未登录时，导入和拆镜已经完成，只是暂停在自动视频理解阶段；不会影响其他 Evan 项目。

步骤 02

准备参考资产

AI 会说明剧情需要怎样的人物、场景和道具，并给出可直接生成的中文提示词。有角色时，最少只需生成或上传一名人物的主参考图；场景和道具没有图片时会直接按提示词生成。

02

一张人物主图即可开始

看文字方案 → 生成或上传人物主图 → 直接进入视频

  1. 在“人物 / 场景 / 道具”间切换，先阅读卡片中的“AI 对剧情的资产要求”。这里展示的是文字方案，不是原视频截图。
  2. 卡片直接显示“可直接使用的中文生成提示词”；可一键复制，并可展开查看跨镜头不变形锚点。
  3. 接受 AI 方案时点 AI 生成主图；“一致性图片模型”可选 Google Flow、即梦、Gemini Web 或 Codex CLI · ChatGPT 生图。使用自己的产品、人物或场景时点 上传替换图，也可点 从素材库选择。
  4. 原片有人物时，至少为任意一名人物生成或上传一张主参考图。主图生成成功后就已达到最低门槛，不必等待全部资产。
  5. 场景和道具图片可全部跳过；每个镜头会自动使用卡片中的场景、材质、产品结构与不变形锚点提示词。需要更强控制时再生成或上传对应参考图。
  6. 面部多角度、全身设定板、场景布局图和产品结构图仍可点击 一键生成剩余 2 张 补齐，但它们属于一致性增强，不会阻止视频生成。
  7. 达到最低门槛后，点 使用当前人物直接生成视频。如果分析结果没有人物，则可直接点 按提示词直接生成视频。
人物：最低准备 1 张

人物主参考图用于锁定五官、脸部骨骼、发型、身材比例和身份记忆点。

正面身份照即可启动；多角度与全身板为推荐增强
场景：可选

没有图片时，自动按空间拓扑、功能区、固定构件、材质和主光方向提示词生成。

可选补充：主场景图 → 多机位布局图 → 材质灯光图
道具 / 产品：可选

没有图片时，自动按轮廓比例、组件、按钮接口、材质、颜色和标志位置提示词生成。

可选补充：正面结构图 → 多角度结构图 → 细节尺度图
【资产主提示词】固定不可漂移的身份、结构、比例、材质与记忆点
【本图任务】只定义当前设定图的角度、排版和展示内容
【生成顺序】严格基于已确认的前序参考图继续生成
【跨镜头锁定】在所有镜头中视为同一人物、同一空间或同一实体
✓
一张图能启动，三张图能提质

人物主图已经足够进入视频生成；补齐多角度和全身设定板可以进一步减少复杂镜头中的变脸、变形和比例漂移，但不再是流程门槛。

步骤 03

生成成片

简单模式自动整理中文生成提示词，并在生成前直接提供视频模型、画幅、分辨率和候选数量设置。系统直接生成镜头视频，不再要求先生成或确认首帧、尾帧。

03

镜头视频 → 最终视频

参考图与提示词自动组合，首尾帧可选

  1. 先在始终可见的“生成参数”中选择 视频模型、画幅、分辨率 和 每个镜头生成数量。下方会显示预计生成任务总数。
  2. 数量默认为 1；可选 1–4 个候选。选择 2 个表示每个镜头各生成 2 条独立视频，平台会按实际任务分别计费。
  3. 点 生成全部未完成视频。Evan 自动把已有的人物、场景、产品参考图与缺图资产的中文提示词组合到每个镜头。
  4. 没有任何资产图的无人镜头会直接走文生视频；只有一张人物图时，它会作为人物资产参考，而不会被误当成证件照式首帧。
  5. 每个镜头只有 1 个候选时，全部成功后自动进入成片；有多个候选时，先逐条预览并点击 选用这个候选，每个镜头选定一条后进入合成。
  6. 如需精确控制某个镜头的开场或收尾构图，可在高级模式打开“关键帧”，选择性生成起始 / 中间 / 结束帧；不做也能继续。
  7. 点 生成最终视频，等待本地渲染完成。最终画布会沿用所选画幅与分辨率。
  8. 完成后成片先保存在当前复刻任务中。需要继续在画布加工时，点击 发送到 AI 画布，画布只创建或更新一个普通视频节点。
推荐人工检查点：人物主参考图

先确认人物身份没有明显错误，再直接生成视频；只有对构图要求特别严格时才需要增加关键帧。

自动中文提示词→自动选择可用资产图→镜头视频→时长校准→本地成片

什么时候使用高级模式

简单模式适合绝大多数复刻。只有需要精细控制时才切换高级模式，已有结果不会丢失。

高级模式中可以控制什么？

可编辑镜头时间线和分析蓝图，检查四层提示词，按动作复杂度生成起始 / 中间 / 结束关键帧，选择视频模型、分辨率和声音，以及调整成片时间线、背景音乐、字幕、转场和连续性检查。

简单模式自动隐藏了哪些内容？

镜头拆分细节、原始提示词模板、当前资产解析提示词、模型优化提示词、逐镜参考图优先级和时长校准策略仍在内部工作；模型、画幅、分辨率、数量和声音这些常用参数会直接显示。

切换高级模式会重新收费吗？

仅查看或编辑不会。只有重新提交图片或视频生成时才会再次使用对应平台额度；本地拆镜、时长校准和最终渲染不使用 AI 生成额度。

失败恢复

遇到问题时怎么处理

项目会保存结构化数据、确认状态和中间结果。多数问题只需重试当前项。

提示发生阶段处理方法是否影响其他功能
Gemini 尚未登录自动分析打开 Gemini 登录，完成后重试未完成分析不影响导入、拆镜和其他项目
分享链接无法解析导入粘贴完整分享文案；仍失败则下载后本地导入不影响本地文件导入
设定图生成失败锁定资产只重试失败图片，或复制对应提示词到外部生成后上传已完成图片会保留
提交状态不确定图片 / 视频生成先检查平台历史和项目素材，确认没有结果再单独重试避免直接批量重试导致重复扣费
视频时长校准失败镜头视频直接重试本地校准，不需要重新生成视频不会再次调用视频平台
更换资产后结果待确认任意下游阶段重新确认当前资产方案并生成受影响的视频；若使用了可选关键帧，再更新对应关键帧这是防止旧资产混入的保护机制
常见问题

登录、提示词和一致性

几个最常见的问题集中说明。

目前没有登录 Gemini，会影响项目运行吗？

不会。Evan 本身、画布、项目、本地视频导入、自动拆镜、素材编辑和本地渲染都能运行。只有简单模式自动进入视频理解阶段时需要登录 Gemini。

为什么画布里找不到“视频复刻”节点？

当前入口是“短视频复刻模板”对应的 Video Analysis 节点，不再创建旧版容器；它会在分析后自动生成关键帧、镜头视频和 Render 成片节点。

成片会自动出现在画布吗？

会。视频分析完成后会自动创建普通的关键帧、视频和最终 Render 节点，用户可以逐个生成并继续编辑。

人物、场景和道具提示词在哪里？

步骤 2 的每张资产卡都会直接显示“AI 对剧情的资产要求”和中文生成提示词，不需要先看视频截图或展开隐藏面板。三张一致性设定图也各自保留对应提示词与复制按钮。

场景、道具和三图参考包必须全部生成吗？

不需要。有角色时，至少准备一名人物的主参考图即可；场景和道具可完全使用中文提示词，多角度或三图参考包只用于增强一致性。没有人物的原片还可以直接文生视频。

不同镜头会不会乱用参考图？

Evan 会结合景别、人物 / 产品交互、模型可接收的参考图数量来排序：人物近景优先正脸和多角度，人物全身优先全身板，产品特写优先产品三图，场景镜头优先主场景和布局图。

原视频和日常 Chrome 用户资料会被修改吗？

不会。参考视频会复制到当前项目；AI 浏览器使用独立共享资料目录，不读取或影响日常 Chrome 的用户资料。
