# Evan AI Video Canvas 当前项目说明

版本基线：`0.1.2`。发布内容以版本 Tag 对应的 commit 为准，不在文档中写死“最新分支”
或某个会迅速过期的 commit。

## 产品定位

Evan 是一个本地优先的 AI 图片、视频和漫剧生产画布：

- 画布编辑、项目管理、素材库、视频剪辑与 Remotion 渲染在本机完成。
- Google Flow、Gemini Web、即梦和 API 模型在对应官方服务器生成，使用用户自己的账号和额度。
- 安装版内置媒体与自动化运行依赖，并复用电脑现有的正式版 Google Chrome；不再打包浏览器。Codex 是可选连接器，CLI 由用户单独安装和
  持续更新，Evan 不捆绑会快速过期的固定版本。
- 项目、素材、配置和浏览器登录 profile 与程序安装目录分离，升级不会覆盖用户数据。
- 新建项目可选择默认目录、桌面、其他文件夹或其他磁盘；所选目录中会生成同名的完整
  项目文件夹和 `project.json`。
- 画布删除本地图片节点时，图片文件与节点快照先移入项目 `.trash/` 回收站；设置菜单可
  在 7 天内恢复或永久删除，到期内容由后端启动检查与每小时清理任务自动移除。

## 当前主要能力

- 文本、图片、视频、音频、字幕、脚本、素材库和成片节点。
- Google Flow、Gemini Web、即梦的图片/视频均通过浏览器登录态发出真实 HTTP 请求。
- 即梦图片 5.0 Pro/Lite 与五个 Seedance 2.0 视频模型；5.0 Lite 当前不消耗额度。
- 图片数量按统一模型能力表限制：Flow 最多 4 张、Gemini Web 1 张、即梦 Pro 最多 4 张、
  Lite 最多 8 张，并支持画布多节点回传。
- 新 Flow 账号自动进入已有项目或创建项目。
- 浏览器自动化默认无头后台执行；设置中保留主动打开浏览器的登录/调试入口。
- AI Browser Hub 以事件驱动方式限制并回收 Evan 明确登记的平台标签；没有任务时 60 秒
  关闭 Chrome，不运行常驻标签巡检，也不处理用户手动打开的页面。
- 登录入口与验证入口分离；打开过页面不算登录，只有三平台各自的只读 HTTP 探针通过后
  才显示“已验证”。
- API 图片/视频模型和提示词优化。
- 角色身份库与造型包。
- 视频裁剪、FFmpeg/FFprobe 媒体处理。
- Remotion 镜头、音频、字幕合成及成片输出。
- Video Remix 阶段式工作流：导入本地、画布或 URL 参考视频，自动拆 Shot，结构化分析
  人物、场景、道具与镜头蓝图，替换资产后生成关键帧和 Shot 视频，并按原剪辑结构通过
  Remotion 输出成片；本地处理与项目恢复不依赖 Gemini 登录。
- 视频节点支持一键识别人声并生成新的带字幕视频；原视频保持不变。识别自动复用 Gemini Web 登录，存在旧版 OpenAI 密钥时优先使用，字幕烧录在本机完成。
- 可选 Codex/Claude 本地编排入口，不作为应用运行前置条件。
- Codex 设置支持自动发现或手动选择本机 CLI、ChatGPT 登录/重新登录和可用状态提示；
  未连接时只禁用 Codex 模型。

## 桌面运行结构

```text
Electron 主进程
├─ React/Vite 画布
├─ Electron utilityProcess 中的 Node 后端（随机 127.0.0.1 端口）
├─ PyInstaller 独立 Ops CLI
├─ 内置 AI Browser Hub 客户端
├─ 系统 Google Chrome + 系统共享 profile-v1
└─ FFmpeg / FFprobe + Remotion
```

安装资源只读、可替换；用户数据位于 Electron `userData/data`。

新建项目默认位于 `data/library/projects/<项目名>/`。选择自定义存放位置后，实际项目
文件夹位于 `<所选文件夹>/<项目名>/`，其中包含 `project.json`、`images/`、`videos/`、
`audio/` 和按需创建的隐藏 `.trash/` 回收站。应用数据目录只保留项目索引和跨平台目录映射，因此现有 `/library/...`
素材地址、生成流程和 Remotion 渲染不需要改变。

## 安装包

| 平台 | 架构 | 安装介质 | 原生运行时 |
|---|---|---|---|
| macOS | Apple Silicon arm64 | DMG + ZIP | Mach-O Ops CLI、macOS FFmpeg；使用系统 Chrome |
| Windows | x64 | NSIS EXE | Windows Ops CLI EXE、Windows FFmpeg；使用系统 Chrome |

平台运行时不可互换。macOS 包必须在 macOS 构建，Windows 包必须在 Windows x64 构建。
仓库的 `Desktop Installers` GitHub Actions 工作流会在两个原生 runner 分别构建，
再创建 GitHub Release。Release 成功后会自动删除 Actions 临时产物，避免每次发布重复
占用约 1GB 以上的 Actions 存储；用户下载与自动更新所需文件继续保留在 Release。

当前测试包未签名。正式公开分发还需要：

- macOS Developer ID 签名与公证。
- Windows Authenticode 签名，减少 SmartScreen 警告。
- 配置正式更新源和发布证书。

## 用户数据位置

- macOS：`~/Library/Application Support/Evan AI Video Canvas/data/`
- Windows：`%APPDATA%\Evan AI Video Canvas\data\`

`library/` 不进入安装包，也不会在普通卸载或升级时删除。共享浏览器 Profile 位于独立的
`SankaiAI/AI Browser Hub` 用户目录，卸载 Evan 不会删除，其他三开 AI App 可继续使用。
自定义项目文件夹同样不会因应用升级而移动；项目使用期间请勿在系统文件管理器中移动
该文件夹。应用内删除项目仍会删除其完整项目文件夹。

## 开发与发布

开发环境要求 Node.js 22+ 和 Python 3.11+。普通安装用户不需要这些环境。

```bash
npm install
npm run setup:automation-runtime
npm test
npm start
```

构建：

```bash
npm run desktop:dist:mac
npm run desktop:dist:win
```

构建前会生成平台图标、清理并重新冻结目标平台运行时，再验证 Ops CLI、FFmpeg 与
FFprobe，防止不同平台二进制混装。Chrome 由应用启动时兼容性探针验证。

## 已知边界

- 浏览器页面属于第三方服务，页面结构改变后可能需要更新自动化选择器。
- 登录 profile 不能预置或分发，每台电脑和每个用户都必须自己登录。
- 生成提交瞬间网络中断时，仍需进一步完善平台历史记录核验，避免不确定状态自动重试。
- 自动更新代码入口已经存在，但未配置正式发布源时保持禁用。
- Modal 相机角度服务和部分 API 能力需要部署地址或密钥，默认安装包不代替这些账号配置。
- Codex CLI 不随安装包更新；使用 Codex 能力的用户需自行保持 CLI 为最新版。安装版只
  维护独立的 `codex-home/`、Evan Skill 和队列桥接。
