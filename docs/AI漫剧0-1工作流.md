# AI 漫剧 0—1 生产工作流

在同一个本地画布中，从一句故事到一条 MP4 成片：

```
输入故事 → AI 生成剧本 → AI 拆解分镜 → 生成角色与场景图 → 生成镜头关键帧
→ 图片生成视频 → 生成角色配音 → 添加字幕 → 添加音乐/环境音/音效
→ 配置镜头顺序和时长 → Remotion 自动渲染 → 输出最终 MP4 成片
```

生图、生视频、配音调用线上官方 API；本地只负责画布、素材、项目管理与 Remotion 渲染，
不运行任何本地生成大模型。

## 一、节点总览

在画布上**双击空白处**或点左侧 `+`，从菜单添加节点。除原有的文本/图片/视频/图片编辑/
视频编辑/故事板节点外，新增「AI 漫剧 · 声音与成片」一组：

| 节点 | 用途 | 是否需要密钥 |
|---|---|---|
| 剧本 / 分镜 | 复用现有**故事板(Storyboard)**能力生成结构化剧本与分镜 | 需要 GEMINI_API_KEY |
| 图片 | 复用 OpenAI / Gemini 等图片接口 | 需要对应密钥 |
| 视频 | 复用海螺 / 可灵 / Veo 等接口 | 需要对应密钥 |
| **配音 (TTS)** | MiniMax 文本转语音；也可导入本地配音 | TTS 需要 MINIMAX_* |
| **音效** | 导入本地音效（电话铃声、环境声、动作音效） | 完全本地 |
| **背景音乐** | 导入本地音乐；对白期间自动压低 | 完全本地 |
| **字幕** | 通用中文字幕，按配音时长设基础时间 | 完全本地 |
| **Remotion 成片** | 组装 manifest、渲染、进度、预览、下载 | 完全本地 |

## 二、连接规则

- 视频镜头、配音、音效、背景音乐、字幕节点 → **连接到「Remotion 成片」节点**，即成为成片输入。
- 文本节点 → 可连到图片 / 视频（提示词），也可连到**配音 / 字幕**（提供台词文本）。
- 视频 → 视频 / 视频编辑（链式），或 → 成片（作为镜头）。
- 「成片」节点是终点，不能作为其它节点的输入。

> 修复点：此前 `useConnectionDragging` 明确**禁止 AUDIO 连接**，现已建立完整音频连接规则。

## 角色身份库与造型包

角色素材采用“身份库 + 造型包”两层结构：

- 身份库固定 4 张：面部特写、基础全身、表情九宫格、人物呈现板。
- 每套新服装建立独立造型包，至少保存：造型全身定妆、造型人物呈现板。
- 同一角色只建立一次身份库；换装时不得重建角色身份。

保存到素材库时，分类选择“角色”。`角色名称` 决定角色身份，`素材用途` 决定素材类型，`造型名称` 决定服装归属；顶部的 `名称` 只是显示标签。推荐使用 `角色名_造型名_素材类型`，例如 `莫妮卡_LOOK_C_黑色丝绒晚宴礼服_全身定妆`。

从素材库导入造型素材时，系统会读取同一角色的身份面部图和同一造型包的全部参考图。该造型素材连接到下游场景图片节点后，这组参考图会自动继续传递，用于同时锁定脸部身份和服装。

素材文件使用唯一文件名保存。即使多个素材的显示名称相同，也不会覆盖同名文件；但为了后期检索，仍应填写清晰名称。

## 三、生成配音（MiniMax TTS）

1. 添加「配音」节点，输入台词文本、角色名。
2. 可选设置 `voiceId`（默认音色林默 = `yuanboxiaoshu`）、语速、情绪。
3. 点「生成配音」→ 调用 `/api/audio/minimax/tts`，音频保存到 `library/audio/`，可试听。
4. 节点会用**配音真实时长**自动回填时间轴结束点。
5. 也可点「导入本地音频」直接使用已有配音。

> 未配置 `MINIMAX_API_KEY` / `MINIMAX_GROUP_ID` 时，会返回明确的「未配置」提示，
> **不会产生任何付费调用**；此时可用「导入本地音频」照常推进。

## 四、音效与背景音乐

- 「音效」/「背景音乐」节点点「导入本地音频」选择文件，自动探测时长回填时间轴。
- 参数：起始/结束（时间轴绝对秒）、音量、淡入淡出、循环。
- 背景音乐额外支持「对白闪避」：对白期间自动压低音量（由清单中 dialogue 音轨的时间窗决定）。

## 五、字幕

- 「字幕」节点输入文本、角色名、起止时间；下方有实时预览。
- 推荐：先用「台词文本 + TTS 音频真实时长」得到基础时间，再手动微调。
- 第一版不做语音识别；后续可扩展导出 SRT。

## 六、配置镜头顺序与时长

- 每个「视频」节点作为一个镜头，直接连到成片节点。
- 镜头顺序：由节点的 `order` 字段决定；未设置时按画布从左到右。
- 镜头时长：由源素材裁剪点 `start/end`（视频编辑节点可裁剪）决定，硬切拼接。

## 七、渲染成片

1. 把视频/配音/音效/BGM/字幕节点都连到「Remotion 成片」节点。
2. 成片节点实时显示：镜头数、音轨数、字幕数；缺失素材会红字列出。
3. 设置合成宽/高/fps（默认 1280×720 / 24）。
4. 点「开始渲染成片」→ 提交 `/api/render/remotion`，节点显示排队/渲染中/进度条。
5. 成功后：内嵌预览成片、下载、在 Finder 中显示、重新渲染。
6. 成片保存在 **`library/renders/`**（已 gitignore）。

细节见 [Remotion 渲染说明](Remotion渲染说明.md) 与 [项目数据格式](项目数据格式.md)。

## 八、常见错误

| 现象 | 原因 / 处理 |
|---|---|
| 提交渲染返回「缺失素材」 | 某节点的素材文件不在 `library/` 内或路径非法；成片节点会列出，补齐后重试。 |
| 「开始渲染」按钮置灰 | 尚未连接任何视频镜头到成片节点。 |
| 配音报「未配置」 | 未设置 `MINIMAX_API_KEY` / `MINIMAX_GROUP_ID`；可改用导入本地音频。 |
| 首次渲染较慢 | 首次会下载 Chrome Headless Shell（约 90MB），仅一次。 |
| 母带/验收失败 | 需系统安装 `ffmpeg` / `ffprobe`。 |

## 九、费用归属

- 生图 / 生视频 / 配音 调用线上官方 API，**费用由对应密钥所属账号承担**。
- 画布编辑、导入本地素材、Remotion 渲染、ffmpeg 母带 **完全本地、不产生 API 费用**。
- 测试与本地验收（`npm run render:e2e-test`）只用 ffmpeg 生成的素材，**不调用任何付费 API**。
