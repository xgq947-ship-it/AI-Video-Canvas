# TwitCanva工作台 Mac管理App

项目根目录中的 `TwitCanva工作台.app` 用于管理本地服务。

双击后会打开原生 macOS 管理窗口，主界面只保留：

- 启动并打开 / 打开工作台
- 停止服务

右上角更多菜单保留：重新检查、重启、打开日志和打开项目文件夹。

服务地址：

- 前端：`http://localhost:5173`
- 后端：`http://localhost:3001`

日志目录：`~/Library/Logs/TwitCanva/`

管理App会将 `com.dasheng.twitcanva.plist` 安装到 `~/Library/LaunchAgents/`，由 macOS `launchd` 托管服务。点击“停止服务”会同时卸载托管任务并关闭前后端端口。

如需重新构建 App：

```bash
zsh launcher-native/build_app.sh
```
