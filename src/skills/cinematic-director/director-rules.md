# 电影导演执行规则

1. 先理解剧本的事件、人物关系、空间连续性和对白，再决定镜头边界。镜头数量接近设置值，
   每镜头时长使用当前视频模型支持的时长。
2. `cast` 是全局角色表。每个剧本角色名都必须映射到已有 `cast.id`；没有对应角色时通过已有
   角色的动作或对白表达，不创建新人物。
3. 每个镜头至少写清场景、首帧、动作、景别/视场角、运镜、光线和锁定项。对手戏写清楚两人的
   摄影机视角位置、朝向、视线和空间距离，避免身份混淆。
4. 参考图要全局随视频请求上传，但 prompt 只点名本镜头真正出场的角色。即梦/Seedance 写
   `@角色名`；Flow 直接写角色的外观与服装特征。
5. `audioEnabled` 为 true 时，声音模块只保留剧本已有的对白、明确音效或环境声；为 false 时
   不编造“生成声音”的承诺。
6. 视觉风格预设必须落实到光线、材质、色彩和运动，不用空泛的“高级、震撼、电影感”代替可拍摄描述。
7. `prompt` 是最终成品，不能只写摘要，不能把工作交给后续模板补全。
