# 火柴人视频导演 Skill

## 已完成范围

本功能作为 AI 画布内部 Skill 实现，不安装到 Codex CLI，也不引入新的运行时。它复用现有画布节点、工作流 JSON 持久化、Gemini Web / Codex CLI 文本执行器、视频生成路由、运行时模型能力注册表和 Remotion 拼接任务。

支持两条链路：

```text
剧本输入 → 火柴人视频导演 → 分镜列表 → Flow 视频生成 → 视频拼接
参考视频 → 视频分析剧本 → 火柴人导演 Skill → 分镜列表 → Flow 视频生成 → 视频拼接
```

参考视频分析只提取故事、动作、对白、声音和视觉连续性，输出的是剧本素材，不是最终分镜。最终镜头数量、镜头边界、景别、构图和运镜必须由火柴人视频导演 Skill 重新推导。

已覆盖：剧本与参考视频输入、视频分析剧本、结构化分镜、严格输出校验、中文/英文 Flow Prompt、比例/尺寸/时长/镜头数/主题/声音配置、单镜头编辑和重新生成、批量并发、失败重试、分镜排序/复制/新增/删除/JSON 导出、按分镜顺序拼接、状态和结果的项目保存恢复。

## 项目扫描结论

| 能力 | 现有实现 | 本功能复用方式 |
| --- | --- | --- |
| 前端/画布 | React + TypeScript，自定义 CanvasNode/ConnectionsLayer | 新增节点类型和独立节点组件 |
| 状态管理 | App 节点数组 + hooks | 新字段直接放入 NodeData，随工作流保存 |

| 拼接 | `renderJobs` + Remotion/FFmpeg | `/api/videos/merge` 生成并轮询渲染任务 |

## 新增核心文件

- `shared/stickmanDirector.js` / `.d.ts`：设置收敛、剧本转换、Prompt 编译、JSON 解析/归一化/校验。
- `server/services/stickmanDirector.js`：内部 Skill 资源加载、DeepSeek/Gemini/Codex 执行、一次修复、拼接清单。
- `server/routes/stickman-director.js`：Skill 模型目录、导演执行、拼接提交/查询/取消接口。
- `src/skills/stickman-video-director/`：system prompt、导演规则、Flow 模板、示例和 Schema。
- `src/features/stickman-director/`：节点 UI、模型目录 hook、前端生成/拼接服务。
- `test/stickmanDirector.test.mjs`：设置、Prompt、Schema、模型路由、参考映射、重试修复、拼接顺序和连接规则回归。

## API

```http
GET  /api/skills/stickman-video-director/models
POST /api/skills/stickman-video-director/run
POST /api/videos/merge
GET  /api/videos/merge/:jobId
POST /api/videos/merge/:jobId/cancel
```

导演模型不可用时不会伪造视频生成结果，也不会把视频分析结果直接降级成最终分镜。真正的视频仍必须经过现有 Flow/视频 Provider。

## 使用方式

1. 在画布空白处右键或双击，选择“一键工作流”中的“火柴人剧本工作流”或“火柴人参考视频工作流”；节点和连线会一次创建。
2. 剧本工作流填写“剧本输入”后直接执行导演；参考视频工作流上传参考视频后直接执行导演，系统会先生成“视频分析剧本”，再调用导演 Skill。
3. 新建节点列表不再展示火柴人工作流内部节点；使用“一键工作流”创建完整链路。旧项目中的“视频分析”节点仍保留兼容读取能力。
4. 在导演节点选择自动/DeepSeek/Gemini/Codex、主题、比例、尺寸、音频和镜头参数，执行规划；DeepSeek 需要配置 API Key。
5. 在分镜节点展开卡片编辑字段、重新编译 Prompt、单镜头生成或批量生成；失败项可单独重试。
6. 在“视频拼接”节点按分镜顺序输出 MP4/MOV/WebM。

节点字段、Task ID、Prompt、结果 URL、错误信息、重试次数和拼接结果都随工作流 JSON 保存；刷新或重新打开项目时由现有工作流恢复逻辑重新加载。

## 已知边界

- 外部 Gemini/Flow/Codex 是否可用仍由用户登录态、模型能力和额度决定；本次未替用户发起付费外部生成。
- 参考视频的原片播放仍由参考视频节点提供；分析阶段的时间段只作为剧本素材，不作为最终分镜时间轴。
- 批量节点当前提供并发、自动重试和失败继续；暂停/恢复不是本次最小交付范围。
